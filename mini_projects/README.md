# AI-Based Battery Health Prediction System

## Overview

This project uses Machine Learning to predict the health condition of a battery based on simulated electrical and operating parameters.

## Objective

The objective is to classify a battery as:

- Healthy
- Warning
- Critical

based on its operating characteristics.

## Input Parameters

The model uses:

- Battery Voltage
- Current
- Temperature
- Charging Cycles

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Google Colab

## Machine Learning Workflow

1. Generate simulated battery data
2. Prepare and explore the dataset
3. Split the data into training and testing sets
4. Train a Random Forest classification model
5. Evaluate model accuracy
6. Predict the health of new battery readings

## Important Note

This is a software-based educational prototype using simulated battery data. It is not intended to diagnose real batteries or replace a Battery Management System (BMS).

## Project Outcome

The system demonstrates how Machine Learning can be applied to battery monitoring and predictive maintenance concepts.
